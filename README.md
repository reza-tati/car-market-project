# 🚗 بازار خودرو

پلتفرم خرید و فروش خودرو، موتورسیکلت و ماشین‌های سنگین

---

## ✨ ویژگی‌ها

- 🚗 **ثبت آگهی** برای خودرو، موتورسیکلت و ماشین سنگین
- 🔍 **جستجوی پیشرفته** با فیلترهای متعدد
- ❤️ **سیستم علاقه‌مندی‌ها** برای ذخیره آگهی‌های موردعلاقه
- 💬 **چت Real-time** بین خریدار و فروشنده (WebSocket)
- 📸 **آپلود تا ۷ تصویر** برای هر آگهی
- 👤 **پروفایل کاربری** و سیستم فروشندگی
- 🔐 **سیستم احراز هویت** با شماره موبایل
- 📝 **سیستم Draft** (ثبت آگهی بدون لاگین)
- 💰 **سیستم پرداخت** برای آگهی‌های اضافی (زرین‌پال)
- 🔔 **نوتیفیکیشن** برای پیام‌های جدید
- 🎨 **طراحی ریسپانسیو** و مدرن (Bootstrap 5 RTL)

---

## 🛠️ تکنولوژی‌ها

| تکنولوژی | توضیح |
|----------|-------|
| **Backend** | Django 4.2 |
| **Database** | PostgreSQL |
| **Real-time** | Django Channels + WebSocket + Redis |
| **Frontend** | Bootstrap 5 RTL + Vanilla JS |
| **Image Processing** | Pillow |
| **Payment** | Zarinpal |
| **Authentication** | Custom Phone Backend |
