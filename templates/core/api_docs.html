API Documentation

برندها مدل‌ها خودروها تصاویر

برندها

GET /api/brands/

لیست تمام برندها

[
    {
        "id": 1,
        "name": "پراید",
        "country": "ایران",
        "logo": "/media/brands/logos/..."
    }
]
POST /api/brands/

ایجاد برند جدید (نیاز به احراز هویت)

GET /api/brands/{id}/

جزئیات یک برند

خودروها

GET /api/cars/

لیست خودروها با فیلتر و جستجو

پارامترها:

  • brand: فیلتر بر اساس برند
  • city: فیلتر بر اساس شهر
  • min_price, max_price: فیلتر قیمت
  • search: جستجو در عنوان و توضیحات
  • ordering: مرتب‌سازی (price, -price, year, ...)
POST /api/cars/

ایجاد خودرو جدید

{
    "title": "پراید ۱۱۱",
    "brand_id": 1,
    "model_id": 1,
    "year": 1400,
    "price": 150000000,
    ...
}

احراز هویت

برای دسترسی به API های write نیاز به احراز هویت دارید.

استفاده از Token Authentication:

curl -X GET http://127.0.0.1:8000/api/cars/ \
    -H "Authorization: Token YOUR_TOKEN_HERE"
